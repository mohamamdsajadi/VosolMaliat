# پرسش‌های باز

Last Updated: 2026-07-15

## پرسش‌های کسب‌وکار

| پرسش | اهمیت |
|---|---|
| معیار دقیق رد صدور برگ اجرا چیست؟ | بالا |
| قوانین ابلاغ و زمان انقضای رد ابلاغ چگونه تعیین می‌شود؟ | بالا |
| مسئولیت نهایی تایید ابلاغ با کدام نقش است؟ | متوسط |
| آیا مدیران می‌توانند taskهای زیرمجموعه را فقط ببینند یا اقدام هم کنند؟ | بالا |
| سیاست مشاهده جزئیات برگ اجرا برای کاربران خارج از کارتابل چیست؟ | بالا |

## پرسش‌های امنیت

| پرسش | اهمیت |
|---|---|
| نقش‌ها در Keycloak realm role باشند یا client role؟ | بالا |
| گروه‌های Keycloak استفاده می‌شوند یا فقط role؟ | متوسط |
| service account برای sync کاربران دقیقاً چه مجوزهایی دارد؟ | بالا |
| endpointهای fake service در staging/production چگونه محدود می‌شوند؟ | بالا |

## پرسش‌های داده

| پرسش | اهمیت |
|---|---|
| شناسه یکتای اصلی برگ اجرا در همه integrationها چیست؟ | بالا |
| منبع قطعی آدرس مودی کدام رکورد `ContactInfo` است؟ | بالا |
| آیا تاریخ‌ها باید با timezone تهران ذخیره شوند یا UTC و فقط در نمایش تبدیل شوند؟ | بالا |
| آیا داده‌های نمونه باید در محیط production غیرفعال شوند؟ | بالا |

## پرسش‌های Workflow

| پرسش | اهمیت |
|---|---|
| business key فرایندها دقیقاً executionPaperId است یا مقدار دیگر؟ | بالا |
| پیام `ExecutionPaperInformed` با چه correlation key باید correlate شود؟ | بالا |
| اگر callback fake/real دیر برسد، timeout چیست؟ | متوسط |
| اگر task بعدی پیدا نشود، رفتار مناسب چیست؟ | بالا |
| آیا فرایندهای فعال بعد از تغییر BPMN باید migrate شوند؟ | بالا |

## پرسش‌های عملیات

| پرسش | اهمیت |
|---|---|
| محیط production کجا و با چه زیرساختی اجرا می‌شود؟ | بالا |
| برنامه backup رسمی چیست؟ | بالا |
| SLA سامانه چیست؟ | متوسط |
| چه تیمی مسئول Keycloak و Camunda است؟ | متوسط |
| لاگ‌ها تا چه مدت نگهداری می‌شوند؟ | متوسط |
