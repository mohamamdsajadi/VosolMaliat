# سامانه صادرکننده برگ اجرا

فیلد `execution_paper.issuer_system` سامانه صادرکننده برگ اجرا را نگه می‌دارد. مقادیر enum `ExecutionPaperIssuerSystem` عبارت‌اند از `SANIM` (سنیم) و `TABRIZ` (تبریز). این فیلد، اطلاعات ثابت برگ است و پس از صدور تغییر نمی‌کند.

مقدار پیش‌فرض برای برگ‌های مسیر صدور فعلی و درج‌های SQL برابر `SANIM` است. مهاجرت SQLite پیش از راه‌اندازی Hibernate ستون را به برگ‌های موجود اضافه و مقدار آن‌ها را `SANIM` می‌کند. اجرای مجدد مهاجرت، مقدار ثبت‌شده `TABRIZ` را حفظ می‌کند. برای اجرای دستی یک‌باره، فایل `src/main/resources/db/manual/008_execution_paper_issuer_system.sql` موجود است.

API جزئیات در بخش `executionPaper` دو فیلد `issuerSystem` و `issuerSystemLabel` را برمی‌گرداند. سامانه صادرکننده با عنوان فارسی، زیر ردیف برگ در صفحه جزئیات و خلاصه جدول و در سند کامل نمایش داده می‌شود. این تغییر، مسیر دریافت یا صدور برگ از تبریز را پیاده‌سازی نمی‌کند؛ مدل و نمایش آن مقدار را پشتیبانی می‌کنند.
